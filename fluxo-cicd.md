# Fluxo de CI/CD

Um fluxo típico de CI/CD em DevOps segue as etapas:

1. Desenvolvedor realiza alteração no código
2. Código é enviado para o repositório (Git)
3. Pipeline é acionado automaticamente
4. Processo de build é executado
5. Testes são realizados
6. Aplicação pode ser entregue (deploy)

## Benefícios

- Automação do processo de entrega
- Redução de falhas humanas
- Entregas rápidas e consistentes

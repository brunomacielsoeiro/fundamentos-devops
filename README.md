# Fundamentos de DevOps

> 🎓 **Contexto acadêmico**  
> Este projeto foi desenvolvido como atividade prática de estudos sobre DevOps,
> abordando conceitos de automação, integração contínua e entrega contínua,
> com o objetivo de compreender a integração entre desenvolvimento e infraestrutura.

---

## 🎯 Objetivos

- Entender o conceito de DevOps
- Explorar práticas de automação
- Compreender CI/CD
- Conhecer ferramentas e pipelines

---

## 📚 Conteúdo abordado

- Cultura DevOps
- Integração contínua (CI)
- Entrega contínua (CD)
- Automação de processos
- Pipelines de build e deploy

---

## 🧠 Aplicação prática

Os conceitos abordados são utilizados em ambientes modernos de desenvolvimento,
permitindo maior agilidade, automação e confiabilidade nos processos de entrega de software.
